这个是相册的服务端
1.安装依赖文件
pip install -r requirements.txt
2.启动服务端程序
python app.py
3.访问前端界面
http://localhost:3000

在界面输入jpg图片的链接，提交后程序会自动转换为tft屏幕可显示的规格，保存在uploads目录内
